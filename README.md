# Minegocio ERP

> Plataforma ERP modular para pequeñas y medianas empresas de Guatemala.

---

## Descripción

Minegocio ERP es un proyecto desarrollado por Compu-Tecnics con el objetivo de ofrecer una plataforma moderna, modular y fácil de implementar para las MIPYMES guatemaltecas.

El proyecto utiliza Dolibarr como núcleo del ERP y añade módulos propios desarrollados por Minegocio para adaptarse a la realidad fiscal, comercial y operativa de Guatemala.

---

## Objetivos

- Plataforma basada en Docker.
- Arquitectura modular.
- Compatible con futuras versiones de Dolibarr.
- Integración con FEL Guatemala.
- Punto de Venta (POS).
- CRM.
- Inventario.
- Tienda en línea.
- API REST.
- Integración con WhatsApp.
- Integración con Inteligencia Artificial.
